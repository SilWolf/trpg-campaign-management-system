# 鍛造工坊物品圖示切割

將 `inputs/` 中的數字命名 JSON 與 2048 × 2048 JFIF 圖片切成 128 × 128 WebP 圖示，輸出至 `outputs/`。

## 輸入格式

- `1.json`、`2.json` 等檔案包含 `items` 陣列，每份最多 64 筆。
- 每筆物品使用 `itemId` 或 `id` 作為輸出檔名，例如 `item-abc123.webp`。
- `1-1.jfif` 對應 `1.json` 第 1–16 筆，`1-2.jfif` 對應第 17–32 筆，以此類推。
- 每張大圖以 4 × 4 排列，從左上開始、由左至右再由上至下；圖片須為 2048 × 2048 JFIF/JPEG。
- 對應圖片可以缺少；該組物品會略過，並在完成時列出提醒。

## 執行

將輸入檔案放入 `inputs/`，然後在專案根目錄執行：

```bash
npm run split:item-icons
```

產生的圖示會寫入 `outputs/`；相同 ID 的既有圖示會被新結果覆蓋。
